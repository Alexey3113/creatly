# ANIMATED — ПРАВИЛЬНАЯ МОДЕЛЬ: иллюстрированный кино-скроллителлинг-лендинг

Пивот: мы ушли в «web3» (шейдеры/частицы/3D). Референсы (5 пинов) показывают ДРУГОЕ —
**иллюстрированный мир, сквозь который зритель плывёт по скроллу**, собранный из слоёных вырезок,
+ полноценный продающий лендинг. Синтез: vision-разбор (Claude) × codex × qwen (kimi застрял).
Референсы: TWILIGHT CITY/SNOW NIGHT · ORIGIN deep-sea dive · VISITE nature-journey · 2 fantasy game-worlds.

## ПРИЁМ (что реально на видео)
- Иллюстрированный мир; камера/персонаж ДВИЖЕТСЯ сквозь главы. Ощущение «плывём» = **dolly** (viewport scale 1.0→1.1) + слои расходятся по скорости, НЕ просто параллакс.
- Многослойная глубина: **bg-плита → midground-субъект → fg-вырезки** (трава/скалы/ветви — рамкой). Атмосферная перспектива: дальние светлее/холоднее (haze), ближние контрастнее.
- **Края растворяются, НЕ режутся**: контактный край плотный, внешние/дальние — feathered; тень под объектом отдельным размытым эллипсом. Никаких stiкер-границ и белого halo.
- **Бесшовность держит ЯКОРЬ** (непрерывный элемент через сцены: персонаж/вертикаль дайва/общее небо), а швы прячутся в **silhouette/occlusion-wipe** (чёрная скала заполняет экран → следующая сцена уже под ней), **shared-sky** (один градиент на весь лендинг, цвет интерполируется по --scroll) или **match-cut** (луна→иллюминатор). Наивный crossfade — нет.
- Мир «дышит» без скролла: idle micro-drift декора ±6px.
- После сильного перехода — тихая зона чтения (не пинить всё подряд).

## СТОП (анти-web3)
WebGL-шейдеры, GPU-частицы, realtime-3D как самоцель — убрать. Снег/светлячки/embers = 10-20 DOM-спрайтов с CSS. Эффект-минимум: параллакс + dolly + мягкие маски.

## WEB-РЕАЛИЗАЦИЯ на ScrollStage/parallax-scene
- `<Layer depth z from/to cursor mask>` уже умеет параллакс+маски. Рецепт глубин на сцену:
  bg `depth .05–.15` (y:0→-4vh) · midground `depth .3–.45` (scale 1.02→1.1 = dolly-якорь) · fg `depth .7–1.0` (большие y, уплывают первыми, cursor 12–20px).
- Мягкий край: PNG-alpha + `mask="soft"` / `mask-image:linear-gradient(#000 85%,transparent)` на нижнем крае; тень = blurred тёмный эллипс (`filter:blur(24px);opacity:.35`) слоем ниже; haze = градиент-оверлей `mix-blend screen`(свет)/`soft-light`(туман).
- Переходы: `SilhouetteWipe` (fg-чёрный силуэт фаза [.7,1]) · `SharedSky` (общий фон, `color-mix` глав по --scroll) · `MatchCut` (общий элемент `position:fixed`, crossfade).
- Pin-scrub только 3–4 ключевые сцены (`heightVh 260–400`), между — быстрые «дышащие» секции. reduced-motion фолбэк уже есть.

## ASSET-KIT (безлимит — можно 50-70/сайт)
Одна сцена = 10–15 ассетов: 1 bg-плита (edge-to-edge, 1920–2160px) · 1–2 midground · 3–5 fg-вырезок · 1 персонаж/маскот(+позы) · 3–6 декор (птицы/фонари/перья/светлячки) · 1–2 тени.
Лендинг = **5–7 полных миров-сцен + 2–3 «лёгкие» главы (фрагмент+карточки)** → ~50–70 ассетов/сайт.
Мягкая вырезка: промпт `isolated [X], painterly, soft brush edges, no hard outline, matched light, plain dark bg` → `higsRemoveBackground` → alpha-feather 1–4px (canvas-скрипт) → painted fringe цветом сцены (без белого halo) → contact-shadow отдельно. Форматы: bg AVIF/WebP, cut-outs PNG/WebP-alpha, fg ≤1600px, bg ≤2160px.

## ПРОДАЮЩИЙ ЛЕНДИНГ — 12 блоков (5–7 сцен + коммерция между)
1 Nav (фикс, лого+якоря+CTA) · 2 Hero-мир (обещание + доказуемый subhead + 2 CTA) · 3 Visual-hook (первый переход/погружение) · 4 Проблема/контекст · 5 Решение = новая глава мира · 6 Три возможности (предметы/иллюстр-карточки) · 7 Как работает (3 шага вдоль пути) · 8 Продуктовый showcase (главный кадр) · 9 Галерея сценариев/сезонов/кейсов · 10 Доверие (цифры/отзывы в стиле мира) · 11 Кульминация + главный CTA · 12 Сделка (цена/регистрация) + Footer (fg тонут, финальный силуэт).
Дуга: обещание → погружение → проблема → решение → доказательства → доверие → кульминация+CTA → сделка.

## АРТ-ДИРЕКШН уровня story2 (не слоп) — правила
1. Один художественный тезис/сайт (техника·эпоха·материал·настроение). 2. Одна физика света (направление·температура·время суток). 3. Ограниченная палитра 2–3 доминанты + 1 CTA-акцент; hex'ы — В КАЖДОМ промпте генерации. 4. Единая детализация (не мешать painterly-bg + glossy-3D + AI-фото). 5. Повторяющийся мотив связывает главы (арка·луна·красная нить·персонаж·свет). 6. Мир больше героя (кино, без зумов вплотную). 7. Типографика — партнёр сцены (1 display + гротеск, цвет из теней сцены). **8. Сначала storyboard 6–8 кадров, ПОТОМ генерация — не наоборот.**

## ПЛАН ПЕРЕДЕЛКИ 30
Этап 0 «scene-kit» поверх parallax-scene: скелеты блоков (`HeroScene/FeatureChapter/GalleryRow/CtaScene`) + переходы (`SilhouetteWipe/SharedSky/MatchCut`) + asset-pipeline (промпт-шаблон → Higs → remove-bg → feather-скрипт → fringe) + shot-scroll-regression.
Этап 1 ПИЛОТ: 1 сайт end-to-end (коммерч. структура → storyboard 6–8 → генерация кита → сборка из блоков → QA на 5 точках скролла) → подтверждение look'а.
Этап 2: доработка кита + чек-лист 12 блоков + 3 перехода.
Этап 3 конвейер: 3–4 сайта/итерация (арт-дирекшн: ключевая сцена+палитра → кит 50–70 → сборка → скриншот-QA).
Переиспользуем: движок, скелеты, переходы, промпт-шаблоны, remove-bg, QA. НЕ переиспользуем иллюстрации/палитры — у каждого свой мир.

## ТОП-3 РИСКА
1. Дрейф стиля Higs → один style-промпт + палитра в каждом запросе; ключевая сцена первой, вырезки сверять с ней; отбраковка 30–50% без жалости.
2. Вес PNG (50–70 = 15–30 МБ) → WebP/AVIF, lazy+async, бюджет ≤8–10 МБ/стр, preload hero-bg (LCP).
3. Усталость от скролла → пинить 3–4 сцены, чередовать «дышащими» секциями.

СТАРЫЕ 30 (шейдеры/частицы) — временно остаются в реестре; переделываем по одному конвейером в новую модель. Существующие модули story/story2/visual-hooks не трогаем.
