ПРАВИЛА ДЕ-ШАБЛОНИЗАЦИИ (главное):
- У каждого сайта S3 и S5 — СВОЙ закон движения и СВОЙ формат. Запрещено совпадение не только классов, но и чисел: phase/depth/from-to/rotate не копировать между сайтами. Один тип раскладки (card-scatter / tracklist / telemetry / timeline / rail / ledger / geotag / receipts / …) — максимум на 2 сайта.
- Переходы НЕ все crossfade: у каждого сайта осмысленный микс `crossfade/curtain/diagonal`, цвет вуали = фон СЛЕДУЮЩЕЙ сцены (без вспышки). Последняя сцена S6 — БЕЗ `transitionOut` (блок остаётся перед футером) — это правило неизменно.
- Тех-ловушки движка (см. lessons в README): `.ps-layer{pointer-events:none}` → CTA делать отдельным absolute-div, не в Layer; дети Layer стакаются grid-строками; `.ps-media` для карточек `width:100%;height:auto` внутри фикс. карточки; для ТЕКСТ-стеков в grid использовать `width:min(Nch,Mvw)` (НЕ max-width — иначе колонка жмётся по min-content и текст наложится); `rotate` в Layer — строка `"22deg"`; fg — `mix-blend:screen`+маска или PNG-cut; пин-реф может протечь текстом → маскировать; светлая сцена → root светлый.
