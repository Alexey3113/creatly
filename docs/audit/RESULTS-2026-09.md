чтобы каждый сайт читался как один сюжет: зритель переходит из сцены в сцену за счёт движения объектов вместе
с ним, застывания, параллакса и игры с фоном. Аудит — [AUDIT-2026-09.md](AUDIT-2026-09.md), ТЗ —
[VISUAL-ARCHITECTURE.md](VISUAL-ARCHITECTURE.md), бриф раскатки — [ROLLOUT-BRIEF.md](ROLLOUT-BRIEF.md).

## 2. Движки (общие примитивы)

- **`components/scene-kit`** — единые часы страницы (один rAF, Lenis первым), якоря, `Actor` (объект едет через сцены
  и причаливает в блоки; `m` — поза для телефона), `Weather`, `Atmosphere` (свет страницы по главам), `Backdrop`
  (плита мира под лендингом), `Follow` (числовые CSS-переменные по якорям).
- **Reel v2** (30 миров + canopy) — партитура «ход → удержание → ход», эстафета копи (двух заголовков не бывает),
  стоп-кадр `freeze`, склейки из мира: `descend/ascend/pan/flythrough/portal/sweep/occlude/lightshift`.
- **StageDeck v2** (story2 + /story) — скраб жестом с доводкой, сборка обложки, shared elements (`data-share`), глубина слоёв.
- **parallax-scene v2** (concept) — `rest/intro` (hero собран при загрузке), `overlapVh` (сцены перекрываются без вуали), `out`.
- **ProSite/bespoke** (50 бизнес) — продукт-актёр, рабочий пин с медиа по главам, CountUp, персона шрифтов в теле.
- **hook-kit** (24 хука) — часы сцены на scene-kit, скраб видео без очереди сиков, WebGL-линза `LensReveal`.
- **ScrollStage** (legacy) — переведён на часы scene-kit.

## 3. По семьям

- **Reel-миры (31):** у каждого актёр мира (дирижабль, ныряльщики, караван, лодка, стадо, лист, макао…), 2–3
  мотивированных склейки, стоп-кадр, погода через швы, плита мира и свет под лендингом, свои скелеты лендингов.
- **story2 (20) + /story (3):** переведены на StageDeck v2, мотивированные переходы вместо «сэмплера Keynote»,
  shared elements, утечки ассетов и водяной знак deity убраны.
- **concept (23):** 0 пустых кадров, hero собран в покое, швы формой концепта (тории, мазок туши, роза-витраж, строб…),
  актёр через все сцены.
- **бизнес (50):** 34 ProSite — 34 уникальные последовательности блоков (клон-схемы сломаны), рабочий пин процесса,
  продукт-актёр; 16 bespoke — второй акт. Кадры «обещание = картинка»: одна собака fetch, мыло lather, посуда clay,
  дом sol, стул form, кикфлип deck, банка comb, чужие бренды (Patek, Blue Note, Astra) убраны.
- **хуки (24):** у всех второй акт по скроллу и финал-обещание; тач ведёт скролл.
- **legacy:** 18 активных — мир fixed-слоем под страницей, камера и свет по якорям, актёры; 12 техно-демо — в архив.
- **главная:** кино-витрина — интро-фильм с листом-актёром, главы бриф → режиссура → сайт, витрины семейств.
