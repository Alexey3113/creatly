# Сквозная визуальная архитектура — техзадание (2026-09-28)

Цель: каждый сайт читается как ОДИН непрерывный фильм. Зритель не листает картинки, а движется
сквозь мир; что-то движется вместе с ним; кадр умеет застывать; глубина настоящая; фон живёт.

Главный сдвиг: **от «стопки сцен» к «одному плану с режиссёрским таймлайном»**. Сцена перестаёт быть
коробкой, которая появляется из ничего и уходит в ничто. Переход — это движение камеры или
физическое событие в мире (пролёт, спуск, портал, перекрытие), а не шторка поверх.

## 1. Пять примитивов

### 1.1 Партитура (Score): ход → удержание → ход
Каждая глава = `hold` (камера почти стоит, копи читается, в кадре одна сцена) + `travel`
(переход в следующую). По умолчанию hold ≈ 40% длины главы (сейчас у Reel — 15%).
Копи передаётся эстафетой: старое уходит до того, как приходит новое — двойных заголовков нет.
Застывание (freeze) — отдельный бит: движение останавливается, кадр чуть обесцвечивается,
выходит титр/цифра — как стоп-кадр в кино.

### 1.2 Склейки (Transitions) — физические, из мира, скраб по скроллу
| тип | что видит зритель | когда брать |
|---|---|---|
| `flythrough` | fg/mid уходящей сцены пролетают мимо камеры (scale→2.5, blur), следующая проявляется из глубины (1.3→1.0) | лес, облака, заросли, толпа, рынок |
| `portal` | камера въезжает в окно/арку/пещеру/иллюминатор уходящей сцены; маска-форма раскрывается до full | двери, гроты, купола, телескоп, окна |
| `descend` | вертикальный спуск/подъём одним полотном, шов = природная линия (поверхность воды, облачный слой) | ныряние, горы, шахты, башни |
| `sweep` | полоса света/тумана/луча цвета мотива проходит по кадру и уносит старую сцену | маяк, фонарь, рассвет, прожектор |
| `occlude` | тёмный силуэт fg вырастает на весь экран → под ним уже новая сцена | скала, ствол, волна, буря, стадо |
| `lightshift` | та же композиция, меняется свет (день→ночь) с вспышкой | сад, город, пустыня |
| `rise` | прежний наезд снизу, но с ведущей fg-кромкой и эстафетой копи | запасной |
Правило: у одного сайта 2–3 разных склейки, и каждая мотивирована миром. Никаких iris/wipe «из презентации».

### 1.3 Актёр (Actor) — объект, который едет с нами
Постоянный слой над сценами (position:fixed), живёт на всём сайте, включая лендинг. Путь задаётся
**якорями**: элементы с `data-actor-stop` (герой, главы, блоки лендинга, CTA) + поза в каждой
(x, y, scale, rotate, opacity, blur). Между якорями — интерполяция по прогрессу скролла.
Может «причаливать» в слот блока (CTA, карточка цены). Источник: вырезка (webp с альфой), DOM/SVG или рой частиц.
Примеры: дирижабль Voyage, фонарь Marrow, луч Lumen, цепочка следов Frost, молния Clothing, продукт бизнес-сайта.

### 1.4 Атмосфера (Atmosphere) — общий фон и погода
- Цвет атмосферы страницы интерполируется по палитре глав (рассвет→ночь), фон лендинга продолжает свет последней сцены.
- Погода — постоянный слой частиц на ВСЁ сайте (листья, лепестки, снег, угли, светлячки, пузыри, пыль);
  частицы пересекают швы и реагируют на скорость скролла (ветер = скорость) — мир движется вместе со зрителем.
- Бэкдроп лендинга: под блоками лендинга живёт закреплённая плита мира (приглушённая, с параллаксом),
  которая меняется по главам — лендинг перестаёт быть «брошюрой на однотонном фоне».

### 1.5 Глубина (Depth) — настоящий параллакс
Разные скорости слоёв: bg ≈ 0.1× (scale +4–6%), mid ≈ 0.4× (+12–18%), fg ≈ 1.2–2× (+30–60%, уходит из кадра первым).
Копи стоит МЕЖДУ mid и fg — трава/скалы перекрывают низ заголовка (текст в мире, а не на стекле).
Frosted-карточки убрать: контраст — локальный скрим сцены + тень.

## 2. Применение по семействам
- **Reel-миры (30 + canopy)** → Reel v2: партитура, склейки из мотива, актёр из мотива, погода, бэкдроп лендинга, копи в мире; лендинг — ломаем общий скелет.
- **Concept (23, parallax-scene)** → движок v2: `rest` (hero виден без скролла), `overlapVh` (сцены перекрываются, вуаль в цвет фона отменяется — J/L-cut без пустых экранов), актёр из бренд-объекта.
- **story2/story (23, дек)** → shared elements (объект перетекает из сцены в сцену, FLIP), мотивированные переходы вместо шторок, постоянный слой-подложка, починка нечитаемых вордмарков.
- **Бизнес (50)** → продукт-актёр по якорям блоков, одна pinned-глава с удержанием, дрейф атмосферы по палитре, ломаем клон-блок diptych и повторы слоганов.
- **Хуки (24)** → «второй акт»: сцена развивается по скроллу и передаёт героя в лендинг.
- **Legacy (30)** → по вердиктам аудита: спасти техники в примитивы, остальное — в архив.

## 3. Метрики приёмки (автоматически, скрипт analitic/audit)
- пустых кадров (coverage<0.03) = 0 на всех семьях (сейчас concept 21%);
- кадров с двумя заголовками сцен = 0 (Reel сейчас на ~четверти рила);
- «кино» (мир в кадре) ≥ 85% длины страницы (Reel сейчас ~60%);
- hero-кадр в покое содержит главный объект и заголовок (concept сейчас пуст у многих);
- у каждого сайта ≥1 актёр и ≥2 разных мотивированных склейки; ни один скелет лендинга не повторяется >2 раз.
