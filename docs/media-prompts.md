# Higgsfield — 40 промптов для фото-ассетов Creatly

Промпты на английском (image-модели дают на нём лучший результат). Каждый выдержан
под один из наших 6 стайлпаков и тип использования. Общие правила зашиты в конце
каждого блока: no text, no watermark, cinematic.

**Соглашения по формату:**
- HERO — широкие атмосферные (16:9 или 21:9), фон под hero/story-poster/gallery-reveal
- CARD — квадрат/4:3, для карточек features/gallery/case-studies
- PORTRAIT — 4:5 вертикальные, для team/testimonials (одно «настроение» на весь сайт)
- SCENE — абстрактные текстуры/градиенты под слой «Сцена» и veil-поверхности

Глобальный суффикс для всех: `, cinematic color grade, no text, no logos, no watermark, high detail, photorealistic`

## Заметки для оценки результатов

- Смотрим на 3 вещи: (1) достаточно ли «места под текст» в hero-кадрах (негативное пространство),
  (2) не выглядит ли как сток (лица/улыбки/«команда в офисе» — красный флаг),
  (3) держится ли единая палитра внутри одного стайлпака.
- Портреты особенно важны: если Higgsfield даёт консистентное «настроение» —
  это то, чего сток не даёт, и наш козырь для team/testimonials.
- SCENE-подложки (29–32) — проверить, читаются ли поверх них белый/тёмный текст
  (это будущая замена CSS-сценам либо фон под них).
