# Visual Hooks — Concept Board

Дата: 29 июля 2026. Источники: [motionsites report](../motionsites/report.md), Pinterest-урожай ([pins.json](pins.json), 156 пинов / 8 семейств), award-галереи (Awwwards, Godly, Dribbble).

Цель доски — сырьё для промптов генерации. Каждый концепт = **один доминирующий объект + один читаемый motion-приём + один визуальный вопрос**.

## Кураторский шортлист сцен витрины

Помечено: **[есть]** — уже в `/visual-hooks`, **[new]** — предложено добавить. Движок: S=`soul_2`, N=`nano_banana_pro`, C=`soul_cinematic`/`cinematic_studio_2_5`, ref+N = финальный кадр через реф + Banana.

1. **Chrome Bloom / Organic 3D** [есть: bloom-protocol / visual-hero] — жидкий хром+стекло, один объект, god-ray. Приём: курсор мягко ведёт объект. Движок: **C** (герой) + **N** (чистый рендер).
2. **Cursor Reveal — Dual State** [есть: prism-veil] — один объект в двух состояниях под движущейся апертурой. Приём: cursor reveal. Движок: **N** (кадр A) → **ref+N** (кадр B: другое состояние).
3. **Cinematic Scrub — Assembly** [есть: orbit-memory / signal-body] — объект собирается/поворачивается по скроллу. Приём: scroll→video.currentTime. Движок: фото-постер **C**, потом видео.
4. **Glass Portal** [есть: glass-passage] — стеклянная карточка/окно содержит другой мир, растёт в новый viewport. Приём: portal expand. Движок: **N** (сцена) + **N** (мир внутри).
5. **Product Theatre** [есть: quiet-machine] — один люкс-объект, тёмная студия, один луч, hover-инспекция. Движок: **C** / marketing.
6. **Editorial Hand-Forward** [есть намёк] — рука с продуктом ближе камеры, чем модель (OYLA). Приём: reveal доказательства. Движок: **S** (люди/руки — сильная сторона Soul).
7. **Kinetic Monolith Type** [есть: monolith-type] — слова становятся архитектурой, ломаются по скроллу. Движок: типографика в HTML + фон **C**.
8. **Split Compare — Twin State** [есть: chromatic-twin] — драг-делитель день/ночь, до/после, природа/техно. Движок: **N** ×2 согласованных кадра (ref+N для второго).
9. **Material Cutaway** [есть: inside-form] — surface/structure в одном объекте, скан по курсору. Движок: **N** (solid) + **ref+N** (cutaway).
10. **Character-led 3D** [new] — маскот/цифровой человек объясняет бренд. Движок: **S** / soul_cast.
11. **Atmospheric Interface** [есть: soft-threshold] — спокойный UI проступает из движущегося цвета. Движок: **C** (атмосфера) + HTML-стекло.
12. **Landscape Fold** [есть: horizon-fold] — пейзаж складывается вокруг идеи человеческого масштаба. Движок: **C**.

## Пайплайн визуала (по решению)

1. **Фото для утверждения** — каждый концепт стартово через **S + N + C** одновременно, разные фоны → выбираем движок и кадр.
2. **Финальный reveal-кадр** (где нужен второй state) — **реф + Banana** (`nano_banana_pro` + исходный кадр), чтобы объект/композиция совпали.
3. **Видео** — только после утверждения кадра, в **макс. качестве** (не оптимизированное), под запись.

Пилот №1: **Chrome Bloom** — 4 движка (nano_banana_pro 4k, cinematic_studio_2_5 4k, soul_cinematic 2k, soul_2 2k), разные фоны. Результаты в `public/uploads/1/hooks/`.
