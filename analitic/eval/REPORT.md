# Оценка: пин ↔ результат, ии-шлак vs нормальные

Метод: скриншот собранного hero каждого из 23 сайтов (sp≈0.7) → codex (GPT-5-codex, vision) сравнивает ПИН и НАШ результат по двум осям (pin_match 0-10, craft 0-10) + verdict + причина. Плюс ручная сверка (я смотрел пины глазами).

## Главный вывод
- **Прямого «ии-шлака» нет.** craft у всех 5–7.5 (среднее 6.4). Никто ≤4 (треш) и никто ≥8 (уровень топ-студии).
- **Слабое место — не артефакты, а «безопасность»:** codex по кругу отмечает, что наши hero **мягче / спокойнее / формульнее**, чем пины. Пины — это дерзкие editorial-постеры (гигантский брутал-шрифт по фото, плотная маргинальная вёрстка, жёсткий контраст). Мы часто уходили в «тёплый кинематографичный luxury-hero» — красиво, но безопасно.
- **pin_match врать нельзя доверять:** многие пины — это og:image-мисматчи (не по теме концепта). Подтверждено глазами: escort-пин = постер «EVEREST», folkmusic-пин = гот-рейв-афиша «ВЕСНА» (мы намеренно ушли в тёплую избу). Плюс из стройки известны: jprestaurant-пин=аниме-обложка, dance-пин=аниме-пинап, freestyle-пин=средневековье, notredame-пин=travel. → низкий pin_match на них — не наша вина, а кривой пин.
